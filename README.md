# 🎓 Projetos de Graduação - Sistemas de Informação

Bem-vindo ao meu repositório acadêmico central! 

Este espaço foi criado para documentar e organizar minha evolução ao longo do curso de **Bacharelado em Sistemas de Informação** no **IFSULDEMINAS - Campus Machado**. Aqui você encontrará desde os primeiros exercícios de lógica de programação até projetos mais complexos de estruturação de software, banco de dados e pesquisa acadêmica.

## 🗂️ Estrutura do Repositório

Para facilitar a navegação, os projetos e listas de exercícios estão organizados por período e, internamente, subdivididos por disciplina:

* 📁 **1-Primeiro-Periodo/**: Fundamentos Web.
* 📁 **2-Segundo-Periodo/**: Aprofundamento em algoritmos e estruturas de dados.
* 📁 **3-Terceiro-Periodo/**: Orientação a objetos, bancos de dados e início de desenvolvimento web mais aprofundado.
* 📁 **4-Quarto-Periodo/**: (Em andamento) Engenharia de Software, desenvolvimento avançado e novas disciplinas.

> **Nota:** Projetos de maior escala ou com foco específico de portfólio (como sistemas completos) podem estar fixados de forma independente no meu perfil principal.

## 🛠️ Tecnologias e Ferramentas

Ao longo dos semestres, estas são algumas das principais tecnologias, linguagens e ferramentas aplicadas nas atividades deste repositório:

* **Linguagens:** C, C#, Java, Python, PHP, JavaScript, TypeScript.
* **Web & Frameworks:** HTML, CSS, React, Node.js, Spring Boot, Django.
* **Banco de Dados:** MySQL, PostgreSQL, SQL.
* **Ferramentas & DevOps:** Git, Apache Ant/Ivy.
