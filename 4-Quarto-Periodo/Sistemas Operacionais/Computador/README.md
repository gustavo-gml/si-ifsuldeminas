#  Simulação de Sistema Operacional

Este projeto é uma simulação didática desenvolvida em Python para ilustrar a arquitetura em camadas e o fluxo de execução de um Sistema Operacional, cobrindo desde a interação da aplicação do usuário até a escrita física no hardware.

---

##  Como Executar

Certifique-se de ter o Python 3 instalado e execute o arquivo principal no terminal:

```bash
python main.py
